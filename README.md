# Procedural Content Generation (PCG)

A procedural content generation project developed in **Unity using C#**, focused on creating different environments through procedural generation. The project features two types of environments: a **town map** and a **mountain map**.

The mountain environment uses **Perlin noise** to generate randomized terrain heights, with different textures applied depending on the terrain's elevation. Trees are also procedurally placed based on height restrictions, with randomized positions, rotations, and sizes to create a more natural environment.

The project also features configurable environmental fog and randomized player spawning.

This project was an opportunity to explore **procedural content generation**, terrain generation, Perlin noise, and environmental object placement in Unity.
